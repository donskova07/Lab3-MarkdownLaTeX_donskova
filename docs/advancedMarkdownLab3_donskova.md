#### Alert-блок 
> [!TIP]**Совет по использованию:** Для экранирования спец символов в Markdown используйте обратный слэш \ Например чтобы написать *курсив* без форматирования, напишите \*курсив\*
#### Escape-символы 
- заголовки без форматирования `\* это не заголовок `
- звездочка как текст: `\*просто звездочка\*`
