Markdown — это легковесный язык разметки, который позволяет форматировать текст с помощью простых символов клавиатуры, оставаясь при этом абсолютно читаемым в виде обычного текста.
___

Основные возможности Markdown
• Заголовки: Создание структуры документа от 1-го до 6-го уровня.
• Форматирование текста: Жирный, курсив, зачеркнутый и подчеркнутый текст.
• Списки: Нумерованные, маркированные (ненумерованные) и списки с чекбоксами (задачами).
• Цитаты: Выделение смысловых блоков и мнений.
• Ссылки и изображения: Интеграция веб-адресов и графики в текст.
• Код: Вставка коротких фрагментов (инлайн-код) или многострочных блоков с подсветкой синтаксиса.
• Таблицы: Построение структурированных данных с выравниванием столбцов.
• Разделители: Горизонтальные линии для визуального отделения разделов.
___
