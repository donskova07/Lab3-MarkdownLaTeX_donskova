## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта
 #### Markdown — простой язык разметки для оформления текста: вместо сложных тегов используют понятные символы (звёздочки, решётки и т. п.).

#### Где применяют: в GitHub/GitLab (README-файлы, задачи), технической документации, заметках (Obsidian, Joplin), блогах, чатах (Discord, Stack Overflow).

#### Зачем разработчикам: быстро и читаемо оформлять тексты, хранить документацию в Git вместе с кодом, легко конвертировать в HTML/PDF, удобно совместно править и рецензировать.
